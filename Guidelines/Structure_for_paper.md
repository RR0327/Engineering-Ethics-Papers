# Simple structure for our paper

1. `Introduction`

Explain that modern apps collect large amounts of user data for personalization, advertising, and analytics.

2. `Types of Data Collected`

- Name
- Email
- Location
- Browsing history
- Purchase history
- Device information

3. `Ethical Concerns`

- Excessive data collection
- Lack of transparency
- Data sharing with third parties
- Security breaches
- User profiling

4. `User Consent`

Discuss whether clicking “I Agree” truly means informed consent.

5. `Dark Patterns`

Give examples such as:

- Hidden privacy settings
- Pre-checked boxes
- Confusing opt-out buttons

6. `Role of Software Engineers`

This is where you can contribute strongly:

- Collect only necessary data
- Use secure storage
- Provide clear privacy notices
- Design honest user interfaces
- Protect data from unauthorized access

7. `Conclusion`

Summarize that ethical data collection requires transparency, minimal collection, informed consent, and strong security.
